Backend implementation completed on branch luo-ancestral-covenant.

- Product catalogue API
- Ten requested traditional products/services with descriptions
- Price-on-request support
- Admin product/service creation
- Admin pricing and visibility controls
- Order API and order management

- Checkout UI and payment callback/cancel pages

Live credentials are intentionally not committed. Configure Supabase, PesaPal, email and WhatsApp credentials in Netlify environment variables before production payment testing.
