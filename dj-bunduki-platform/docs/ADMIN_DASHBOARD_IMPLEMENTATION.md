# DJ Bunduki Admin Dashboard Implementation

## Route

/admin

## Modules

- Dashboard
- Mix Management
- Event Management
- Blog Management
- Video Management
- Gallery Management
- Product Management
- Advertisement Management
- Booking Management
- Analytics
- User Management

## UI Requirements

- Dark luxury dashboard theme
- Responsive sidebar
- Mobile navigation
- Role-based menu visibility

## Permission Rules

SUPER_ADMIN:
Full access.

CONTENT_MANAGER:
Content modules only.

EDITOR:
Blog, events and gallery.

ANALYST:
Analytics only.

## Initial Dashboard Cards

- Total Mixes
- Total Plays
- Downloads
- Bookings
- Advertisement Impressions
- WhatsApp Clicks

## Implementation Order

1. Admin layout

3. Dashboard widgets
